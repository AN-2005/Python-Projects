# 📝 To-Do List Application

A simple command-line To-Do List application built using Python. Users can add, view, and delete tasks through a menu-driven interface.

---

## 📌 Features

- Add new tasks
- View all tasks
- Delete tasks
- Menu-driven interface
- Input validation for menu choices
- Simple and beginner-friendly

---

## 🛠️ Technologies Used

- Python 3
- VS Code
- Git
- GitHub

## ▶️ How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python app.py
```

# Python Calculator

A simple command-line calculator built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by Zero Handling
- Runs continuously until the user exits

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python app.py
```

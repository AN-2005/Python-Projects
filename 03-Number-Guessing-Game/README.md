# Number Guessing Game

A simple command-line game built using Python where the player tries to guess a randomly generated number.

## Features

- Random number generation
- Unlimited guesses
- Too High / Too Low hints
- Counts total attempts
- Simple command-line interface

## Technologies Used

- Python 3
- VS Code

## How to Run

```bash
python app.py
```

## Concepts Learned

- random module
- while loop
- if-elif-else
- break statement
- Variables
- User Input

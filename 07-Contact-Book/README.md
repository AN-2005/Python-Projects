# 📞 Contact Book

A simple command-line Contact Book application built using Python. Users can add, view, search, and delete contacts using a menu-driven interface.

---

## 📌 Features

- Add new contacts
- View all contacts
- Search contacts by name
- Delete contacts
- Menu-driven interface
- Uses Python dictionaries for efficient data storage

---

## ▶️ How to Run

1. Open the project in VS Code.

3. Run:

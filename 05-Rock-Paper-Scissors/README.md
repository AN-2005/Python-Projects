# ✊ Rock Paper Scissors

A simple command-line Rock Paper Scissors game built using Python. The user plays against the computer, which randomly selects its move.

---

## 📌 Features

- Play Rock, Paper, Scissors against the computer
- Random computer choice
- Winner determination based on game rules
- Input validation
- Easy-to-use command-line interface

---

## ▶️ How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python app.py
```

# 🔐 Password Generator

A simple and secure Python application that generates random passwords based on the user-defined length. The generated password contains uppercase letters, lowercase letters, digits, and special characters, making it strong and secure.

---

## 📌 Features

- Generate random passwords
- User chooses the password length
- Minimum password length validation
- Includes:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!, @, #, $, etc.)
- Randomly shuffles characters for better security
